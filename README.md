# PinePaper Studio — Claude plugin marketplace

This repository is a **Claude plugin marketplace**. It lets Claude (Claude Code or
the claude.ai desktop app) author animations, motion graphics, and vector
micro-interactions with [PinePaper Studio](https://pinepaper.studio), grounded in
PinePaper's design knowledge graph (the `pp:` ontology).

> Generated by `scripts/build-skill-bundles.js` in the PinePaper repo — do not
> hand-edit; push regenerated output here.

## Install

**Claude Code (CLI):**
```
/plugin marketplace add pinepaper/pinepaper-claude-marketplace
/plugin install pinepaper
```

**claude.ai (desktop):** Settings → Connectors → **Add marketplace** → paste
`https://github.com/pinepaper/pinepaper-claude-marketplace`, then install **pinepaper**.

The plugin bundles an MCP connector (`.mcp.json` runs `npx -y @pinepaper.studio/mcp-server`)
and the `pinepaper-studio` skill (procedural knowledge + the design-KG reference).
You need [Node.js](https://nodejs.org) for the MCP server to launch.

## What's here

- `.claude-plugin/marketplace.json` — the marketplace manifest.
- `pinepaper/` — the `pinepaper` plugin: `plugin.json`, `.mcp.json`, and the
  `pinepaper-studio` skill (`SKILL.md` + `references/`, including `design-kg.md`,
  the agent-facing projection of the ontology).

Full guide: https://pinepaper.studio/api/guides/skills
